# Boundless

> 余生也有涯，而知也无涯。

一个持续整理的个人思想与方法论笔记集，并提供配套的 **AI Skill**。这里记录的是关于**如何在有限的生命里，用有限的金钱、时间、精力和认知，获得尽可能多的快乐、自由与人生选择权**的思考。

它更像一份不断生长的个人知识库（Personal Knowledge Base），内容会随着阅读、经历和反思持续更新。配套 Skill 让 AI 助手能直接基于这些内容，为你提供结构化的**行动指南与生活决策建议**。

## 📚 内容概览

### [philosophy.md](philosophy.md) — 融合多思想的完整人生哲学

把六种思想放在同一个模型里讨论，并划分出**认知、身体、消费、处世、生命观**五个层次：

- **孙学、黄毛理论** —— 如何提升自己，以及怎样不被外界评价牵着走
- **薄肌理论、性压抑理论** —— 身体、欲望、自信与亲密关系
- **田忌赛马式消费** —— 怎样分配有限的钱，让每一分钱产生更高价值
- **李伯清的快乐经济** —— 赚钱究竟是为了什么（十六字方针：**耍中找钱，找钱来耍，找耍结合，以耍为主**）
- **上善若水、顺其自然** —— 什么时候进取，什么时候顺势，什么时候放手
- **生也有涯，知也无涯** —— 时间与注意力有限时，该学什么、追求什么、放弃什么

文末给出一份可当作**每月复盘清单**的个人生活决策框架，覆盖事业、身体、行动、金钱、快乐、关系、变化、时间八个模块。关系是否成立、怎么说、何时停，见 [tongxue.md](tongxue.md)；个人择偶排序见 [partner.md](partner.md)；面对无关评价、疑似控制关系怎么少内耗与远离，见 [sure.md](sure.md)；舆论场里的站队、卖惨与网暴，见 [annaofenpei.md](annaofenpei.md)；AI 的位置、技术奇点与文明尺度，见 [scifi-future.md](scifi-future.md)。

核心结论：

> **尽力而为，不强求一切；持续进步，不与所有人竞争；认真赚钱，也认真生活。**

### [sunxue.md](sunxue.md) — 孙学：小镇青年落地执行版

从一场四小时的对谈中浓缩出的 12 条行动建议，主题包括：把数据投喂给 AI、建立自己的信息库、零成本套利免费额度、把人生当游戏体验、走出去看世界、用自媒体记录、去全球找价差、顺势而为、大胆做异类等。

### [tongxue.md](tongxue.md) — 童学：关系里的判断与行动

从童锦程的直播、约会记录和搭讪解析中抽出的判断规则。素材是 9 段一手字幕，约 20 万字。它不替代总纲，只回答关系里的三个动作：继续投入、把需求说清楚，还是放手。

五条模型：

- **吸引力大于讨好**：别人因为你值得靠近而喜欢你，不因为你更努力地讨好
- **给台阶**：先给一个能说服对方自己的理由
- **人性不可考验**：需求直接说，不用消失来测试
- **炫耀即暴露**：反复强调的标签，往往指向不安全感
- **成功前后是两个世界**：低谷时的靠近，和上升期的围拢，不是同一件事

核心判断：

> 如果你不确定对方喜欢你，就按不喜欢来处理。真诚不一定得到爱，不真诚一定会失去。

这套笔记只用于情感、人际和个人成长，不用作纯商业决策。个人的择偶排序仍以 [partner.md](partner.md) 为准。

### [partner.md](partner.md) — 恋爱与择偶笔记

以排序形式整理的个人观察笔记，包含吸引力要素排序、脱单难度城市排序、约会地点推荐度排序、约会流程，以及结婚择偶标准的优先级。择偶的终极目标是内心平静与长期幸福，而非地位或经济利益；婚姻是选能共享利益、共担风险的人生合伙人。童学判断一段关系是否成立；这份笔记记录你自己要什么。

另收录**成龙谈爱情与婚姻**：整理自 2015 年 4 月 7 日他 61 岁生日当天在清华大学的自传《还没长大就老了》首发式及相关媒体专访（京华时报、人民网、中新网），按「婚姻的起点」「婚后的防御」「1999 年的转折」「没有爱情但感情更重」「他欣赏林凤娇什么」五节编排，逐条附原文出处。

> 「爱情很短的，感情才长。」

这部分同时标出了他自我否定的内容（「你们看，我年轻时是这么坏的一个人」），并给出阅读边界：这是一个人对自身一段婚姻的回溯性自述，不是婚姻理论，也不是可效仿的范本。早年控钱、准备离婚、转移财产的做法，是防御性关系设计的反面教材。

### [sure.md](sure.md) — 确实理论：少争辩，把精力放回主线

网络梗化的沟通策略：先接住、再决定要不要辩，不向无关的人自证。情绪稳定的高境界不是硬控情绪，而是减少不必要的情绪开支——该争取的利益要争取，该维护的边界要维护；对毫无利益关系的评价，建议直接「确实」。人生不是上市公司，没有义务向每一位股东解释经营情况。

另含**疑似 NPD / 高自恋控制**的行动指南（非医学诊断）：识别煤气灯与边界入侵、灰石与资源隔离、分级远离，以及可复制的拒控/断联话术。对这类人，「确实」是情绪断供，不是讨好换安全。

### [annaofenpei.md](annaofenpei.md) — 按闹分配：弱传播在舆论场里的现实变形

把邹振东《弱传播》的规律落到内地社交平台与短视频上：注意力、同情、压力甚至赔偿与处罚，按「谁闹得更响」分配，而不是按事实、规则和责任。四大规律收成四句：**弱者优势，情感强势，轻者为重，次者为主**。四条规律只说明什么容易被相信——真正的侵害、贫困与权力欺压仍应被看见；按闹分配开始的地方，是有人用「我更弱」替换「事情是这样」。

给出两套行动指南：**旁观者**（先停转发、只传递有出处的句子、把卖惨叙事拆成「真假 / 钱与责任 / 是否带货或号召人肉」三列）与**被网暴者**（离开评论区、找一个线下的人、固定证据、平台投诉、110 报案，必要时申请人格权侵害禁令）。涉及公开事件时只采用有机构通报或生效判决的材料，存在争议的一并写上。

边界同样写清：受害者求助、依法检举、尖锐但没有谩骂的批评都不算按闹分配；事实核对不是网暴，捏造、人肉、株连、侮辱才是。个人对话里的无谓争吵仍用「确实」（见 [sure.md](sure.md)），遇到捏造事实和网暴不能用它把错误接住。

### [scifi-future.md](scifi-future.md) — 科幻与未来：刘慈欣的八个判断

2026 年是《三体》首发连载 20 年，10 月 10 日《人民日报》第 06 版刊出记者陈圆圆对刘慈欣的专访。这份笔记只收他在访谈里给出的判断，按创作、AI、文明、价值四组展开：

- **内容与机遇相乘** —— 内容是 X，机遇是 Y，一个是零，结果全是零
- **科幻泛化** —— 科幻渗透到生活方方面面，科幻文学本身反而被冲淡
- **对 AI 的「另类的爱」** —— 人类在智能与体力上都有天花板，只有 AI 能冲破；那个未来也许不属于人类，但仍然有意义
- **奇点可能被简单化** —— 人类还有底牌；更可能是人机融合，「我们打不过但可以加入它」
- **AI 是「哲学上的他者」** —— 越过奇点之后，AI 就变成了「外星人」
- **「人的抵达」** —— 派机器去不够，太空探索要是「有人」的航行
- **「不要回答」的落地** —— 该不该回复外星人是个常识，那条指南可操作性不强
- **人文科学是价值锚** —— 技术替代得越多，判断基本价值越只能由人文来回答

文末把这些判断折成四条可用的个人选择原则（能力是乘数、把钱和精力放在只有人能做的判断上、不押单点预测、经历不能外包），并写清边界：这是受访者的个人观点与文学推论，不是科学结论，也不是 AI 的时间表，不宜据此做投资或职业的确定性判断。

## 🧭 AI Skill：boundless-advisor

把本仓库的思想体系打包成了一个可安装的 Skill。安装后，你可以直接用自然语言询问人生规划与生活决策问题，AI 会按结构化的六步流程给出建议。

### 它能做什么

| 场景 | 示例提问 |
| --- | --- |
| 职业与行动 | 「我该不该辞职创业？」「怎么规划未来五年？」 |
| 金钱与消费 | 「钱不够花，该怎么分配？」「这笔钱该不该花？」 |
| 处世与心态 | 「我总在意别人怎么看」「学不完，很焦虑」 |
| 少争辩 / 确实理论 | 「亲戚说我没出息怎么办」「网友抬杠要不要回」 |
| 疑似控制 / NPD | 「对方煤气灯怎么办」「怎么灰石断联」 |
| 舆论与网暴 | 「这个热搜该不该转」「被网暴了怎么办」 |
| 科幻与未来 | 「AI 会不会取代我的工作」「还要不要学文科」 |
| 爱情与婚姻 | 「成龙怎么看婚姻」「在一起久了没激情，是不是不爱了」 |
| 生命观 | 「赚钱到底为了什么？」「工作太累，没时间生活」 |
| 关系判断 | 「她忽冷忽热，是不是喜欢我？」「我想消失几天试试他」 |
| 择偶偏好 | 「择偶应该看重什么？」「约会去哪」 |

### 工作方式

Skill 内置一条 **六步决策流程**：定位问题类型 → 追问关键信息 → 用四资源模型（时间/精力/金钱/认知）拆解 → 用八模块框架定位 → 给出可执行建议 → 收束成一句判断。

知识来源为 `references/` 下的七份文档快照，**离线可用**；也可运行脚本同步仓库最新内容：

```bash
bash boundless-advisor/scripts/sync-knowledge.sh
```

### 安装

**方式一：使用 WorkBuddy**

在 WorkBuddy 中导入 `boundless-advisor` 目录（或 `.skill` 包）即可，Skill 会自动被识别。

**方式二：Cursor**

将 `boundless-advisor` 目录放入项目的 skills 目录：

```bash
# 项目级（推荐，随项目共享）
mkdir -p .cursor/skills
cp -r boundless-advisor .cursor/skills/

# 或全局安装
mkdir -p ~/.cursor/skills
cp -r boundless-advisor ~/.cursor/skills/
```

**方式三：Codex / 其他支持 Skill 的工具**

这些工具遵循通用的 Skill 规范（`SKILL.md` + 资源目录）。将 `boundless-advisor` 整个目录复制到对应工具的 skills 目录即可：

```bash
# 通用做法：克隆仓库后复制 skill 目录
git clone https://github.com/MiChuan/Boundless.git
cp -r Boundless/boundless-advisor <你的工具的 skills 目录>/
```

> Skill 本质是一个纯文本目录，不依赖任何编译产物。若你的工具只支持上传压缩包，可自行打包：
> `cd boundless-advisor && zip -r ../boundless-advisor.zip .`

## 📝 写作约定

为保证良好的阅读与渲染体验，仓库内所有文档遵循以下规范：

- 使用标准 **CommonMark** 语法
- **中英文与数字之间加空格**，中文标点使用全角
- 引用先哲原文与核心结论统一使用引用块（`>`）
- 对比性内容优先使用表格，并列内容优先使用列表
- 文件末尾保留一个换行符
- **文件名使用 ASCII 小写**（语义英文或拼音，如 `philosophy.md`、`sunxue.md`、`annaofenpei.md`），不使用中文文件名
- 新增一份文档时，同步更新 `boundless-advisor/references/` 快照、`boundless-advisor/SKILL.md`、`boundless-advisor/scripts/sync-knowledge.sh` 与本文档
- 引用外部文章、访谈、通报与判决时注明出处与日期，不改动原意
- 所有文档通过 Markdown 语法校验，无告警
- `boundless-advisor/SKILL.md` 的 frontmatter 仅使用标准字段（`name`、`description`、`license`、`metadata`），以保证跨平台兼容
